# MikroTik Scripts

В этом репозитории я собираю и храню скрипты для RouterOS (MikroTik), которые пишу для автоматизации своих задач и использую сам.

## Список скриптов

### 1. Link Monitor ([link_monitor.rsc](link_monitor.rsc))
Скрипт для мониторинга состояния сетевого интерфейса. При переключении статуса (UP/DOWN) отправляет уведомление в Telegram.

### 2. BassDrive Manager ([bassDriveManager.rsc](bassDriveManager.rsc))
Основной скрипт для автоматической записи радио BassDrive на USB-флешку. Проверяет свободное место, получает название текущего шоу через API и управляет процессом записи.

### 3. BassDrive Recorder ([bassDriveRecorder.rsc](bassDriveRecorder.rsc))
Вспомогательный скрипт, который запускает `tool fetch` для захвата аудиопотока. Работает в паре с менеджером.

## Как использовать
1. Скопируйте содержимое нужного `.rsc` файла.
2. Откройте терминал в WinBox или через SSH на вашем MikroTik.
3. Вставьте код или загрузите файл в `Files` и выполните `/import file-name.rsc`.
4. Не забудьте настроить переменные (например, `botToken`, `userId` и т.д.) внутри скриптов под свои нужды.
